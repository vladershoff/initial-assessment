ТЗ. Уровень 1

Необходимо реализовать сервис управления ссылками (Link Storage Service).

Сервис позволяет сохранять ссылки, получать их по короткому идентификатору и вести статистику обращений.

Модель данных

Link {}

id — уникальный идентификатор
short_code — короткий код ссылки
original_url — исходный URL
created_at — время создания
visits — количество переходов по ссылке

Функциональные требования

1. Создание короткой ссылки

POST /links

Request

{
  "url": "https://example.com/some/very/long/url"
}

Response

{
  "short_code": "abc123"
}

Сервис должен:

— сгенерировать short_code  
— сохранить ссылку в базу данных  
— вернуть short_code в ответе


2. Получение оригинальной ссылки

GET /links/{short_code}

Response

{
  "url": "https://example.com/some/very/long/url",
  "visits": 15
}

При каждом запросе необходимо увеличивать счётчик visits.


3. Получение списка ссылок

GET /links

Поддержка пагинации.

Query параметры:

limit  
offset


4. Удаление ссылки

DELETE /links/{short_code}


5. Статистика

GET /links/{short_code}/stats

Response

{
  "short_code": "abc123",
  "url": "https://example.com",
  "visits": 15,
  "created_at": "timestamp"
}


Технические требования

— Язык: Go (по возможности использовать стандартную библиотеку)  
— Использование базы данных для хранения ссылок  
— Использование кеширования для ускорения получения ссылки  
— Конкурентно-безопасная работа сервиса  
— Применение принципов чистого кода и чистой архитектуры
— конфигурация через переменные окружения  
— README с инструкцией запуска
